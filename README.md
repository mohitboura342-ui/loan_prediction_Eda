# Loan Prediction Analysis Project

## 📌 Project Overview
This project focuses on analyzing loan applicant data to identify the key factors influencing loan approval decisions. Using Python-based data analysis and visualization techniques, the project explores relationships between applicant income, credit score, loan amount, and loan approval status.

The main objective of this project is to perform Exploratory Data Analysis (EDA), discover meaningful insights, and understand the patterns affecting loan approval outcomes.

---

## 🎯 Objectives
- Analyze customer financial and demographic information
- Identify factors affecting loan approval
- Perform univariate and bivariate analysis
- Visualize approval and rejection patterns
- Generate business insights from loan data

---

---

## 📊 Key Insights

### ✔ Credit Score Impact
Applicants with higher credit scores have a significantly greater chance of loan approval.

### ✔ Income Relationship
Higher income slightly improves approval probability, but credit score remains the most influential factor.

### ✔ Loan Amount Effect
Higher loan amounts negatively affect loan approval chances.

### ✔ Approval Pattern
Applicants with both high income and strong credit history show the highest approval rate.
